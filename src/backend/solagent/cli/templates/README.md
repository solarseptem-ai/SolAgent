# {{name}}

AI agent project powered by [SolarSeptem Agent](https://github.com/solarseptem/solagent).

## Quick Start

1. Install dependencies:
   ```bash
   pip install -e .
   ```

2. Set your API key:
   ```bash
   export OPENAI_API_KEY=your-key-here
   ```

3. Run the agent:
   ```bash
   solagent run
   ```

## Project Structure

- `solagent.yaml` — Main configuration
- `agents.yaml` — Agent definitions
- `tasks.yaml` — Task definitions
- `main.py` — Entry point
